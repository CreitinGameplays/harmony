CONST-01 - not a compile-time constant

WHAT   A `const` is inlined at every use site, so its value must
       be known when the program is compiled.
WHY    There is no storage for a constant to read at run time;
       the initializer is copied into each use. A value that
       depends on run-time work cannot be inlined.
BAD    const N: i32 = compute();
GOOD   const N: i32 = 42;   let n = compute();
NOTE   Literals, arithmetic on literals, other constants, and
       array/struct literals are all allowed.
SEE    docs/harmony.md - 6.2, 16.10 Code catalogue
